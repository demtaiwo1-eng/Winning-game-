# EPHINTA contributor and intellectual-property clearance register

**Purpose:** Track evidence required before distributing EPHINTA source commercially.  
**Status:** Template only; entries must be completed by the rights holder. This is not a legal opinion.

| Item | Evidence required | Owner / reviewer | Status |
|---|---|---|---|
| Project owner authority | Identity of rights holder and authority to license the project | Rights holder | Pending |
| Human contributors | Names/roles, contribution dates, commit ranges and signed assignment or licence | Rights holder | Pending |
| Contractors/employers | Contract clauses, work-for-hire status where applicable, employer permissions | Rights holder / counsel | Pending |
| Open-source dependencies | Generated inventory, SPDX identifiers, exact versions and notices | Engineering | Pending |
| Fonts/icons/images | Source URL, creator, licence, commercial rights, attribution requirements | Design / counsel | Pending |
| Music/audio/video | Composition, master recording, performer, publisher, territory, term and usage rights | Rights holder / counsel | Pending |
| Brand/trademarks | EPHINTA name, logo, third-party marks and permissions | Rights holder / counsel | Pending |
| Generated/AI-assisted material | Provenance, applicable tool terms and human contribution records | Engineering / counsel | Pending |
| Customer/test data | Confirm no real personal data or production database records in package | Engineering / privacy reviewer | Pending |
| Secrets and signing materials | Confirm no credentials, API keys, certificates or private signing keys in package | Security reviewer | Pending |
| Buyer licence | Final approved commercial source licence | Counsel | Pending |
| Sales terms | Seller identity, taxes, refunds, support, updates and dispute process | Rights holder / counsel | Pending |

## Evidence handling

- Store signed agreements in a restricted legal records location, not in this public repository.
- Record document identifiers and review dates here; do not upload personal identity documents or confidential agreements to a public repo.
- A contributor's Git commit history is not an assignment of copyright.
- A dependency licence scanner is not proof that all dependencies and bundled assets are commercially cleared.
- Do not mark any item approved without an actual supporting document and reviewer.
