# ESS build roadmap (one prompt = one phase = one zip)

1. Foundation: monorepo, Postgres schema (all entities), auth, CI, devcontainer  <- this zip
2. Events: events, guests/RSVP, checklists, budget  <- DONE (phase 2)
3. Marketplace: vendor profiles, shops/showrooms, listings, search + geo radius, reviews
4. Money: wallet, ledger, escrow, payment provider port (Paystack/Flutterwave), webhooks, commissions
5. Growth: subscriptions, promotions/ads, notifications, messaging (realtime)
6. Ops: dispatch riders, verification/KYC, admin API, audit
7. Web app (React + Vite + i18n + multi-currency)
8. Mobile app (Capacitor wrapper of web app)
