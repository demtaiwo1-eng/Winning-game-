# EPHINTA third-party notices

This file records the third-party software and platform materials used by EPHINTA. The obsolete parent-level `eventsss123/node_modules` tree and its stale package manifests were removed; the maintained application dependency source is `eventsss123/eventsss-main/package-lock.json`. It must be regenerated from that exact release lockfile and installed package contents for every commercial release.

## npm dependencies

The 2026-11-13 lockfile metadata inventory found 750 third-party package entries across 12 declared licence types/expressions, with no third-party entry marked UNKNOWN or UNLICENSED in that snapshot. The complete package/version list and verbatim package licence/NOTICE files are generated by:

```bash
cd eventsss123/eventsss-main
npm ci
node scripts/qa/ephinta-license-inventory.mjs
```

The generated release artifact is named `ephinta-dependency-license-inventory`. The latest CI run inventoried 750 packages across 12 declared licence expressions, with zero UNKNOWN/UNLICENSED entries and zero missing usable licence texts. It included 312 distinct notice/licence texts; 107 package entries used the official SPDX standard text as a fallback because their installed package omitted a licence file. For those fallback entries, verify the package-specific copyright line and any additional upstream NOTICE before distribution. Do not ship a release with unresolved UNKNOWN/UNLICENSED packages or missing licence text without a documented legal disposition.

Licence families observed include MIT, ISC, Apache-2.0, BSD-2-Clause, BSD-3-Clause, MPL-2.0, BlueOak-1.0.0, Unlicense, CC-BY-4.0, MIT-0, 0BSD, and MIT OR CC0-1.0. Retain required notices and attribution; do not apply EPHINTA's commercial terms to dependencies.

## Platform and service materials

- **Gradle wrapper:** generated Gradlew scripts retain their upstream Apache-2.0 notice headers. Keep the headers and wrapper distribution notice.
- **Capacitor / Android / iOS:** third-party platform and plugin terms apply to native builds.
- **Capgo updater:** optional third-party mobile update service; verify account terms and privacy/security controls before enabling.
- **Bytid:** external hosted KYC service; subject to provider terms, data processing terms, consent and privacy disclosures.
- **OPay:** external payment provider; use only the official merchant API, credentials, and merchant terms.
- **Nodemailer / SMTP provider:** Nodemailer package licence is covered by npm inventory; the actual mail transport provider has separate service terms.
- **S3-compatible object storage:** storage provider terms and data-processing obligations apply.

## Media

No third-party audio recordings are currently bundled in the web application. Audio remains disabled until the platform owner records a rights-cleared source in `docs/assets/asset-rights.json`. Visual brand assets still require owner provenance confirmation; see `docs/ASSET_RIGHTS_REGISTER.md`.

## Important

This notice is a release-maintenance index, not a legal opinion. Package metadata does not replace review of each actual licence and NOTICE file. The generated artifact should accompany each release binary and be reachable from the product's legal notices screen or documentation.
